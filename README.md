# FISH Scholar: Access Conversation

A small, student-controlled conversation preparation prototype by Dr. Eric Fishon. It helps a learner describe a course barrier, identify what has helped, and edit a draft for a conversation with a human. It is one possible module of the broader FISH Scholar research vision.

## Try it

Download `index.html` and open it in a modern browser. No installation, account, API key, or server is needed. Use **Load fictional example** for a demonstration. Entries remain in the current browser page and are not saved or sent by the app. An optional link opens a separate Anam voice demonstration; no draft text is transferred to it.

## Boundaries

- This independent prototype is not a University of Florida service.
- It does not determine disability status, eligibility, or accommodations; it does not submit a request.
- The UF links are ordinary external links to official guidance and should be checked for changes. The optional Anam link is an independent third-party demonstration, not an embedded service or a NaviGator integration.
- Do not use actual student records in a public demo. A future research study or UF deployment requires its own privacy, accessibility, institutional, and research review.
- The app currently uses a deterministic text template. **It does not use AI or NaviGator.** An AI-assisted version is a proposed research direction.

## Research connection

The proposed UF FYCS non-thesis pathway is: Paper 1 identifies student needs; Paper 2 maps resources and residual gaps; Paper 3 tests whether a bounded, human-guided tool addresses a supported gap. This code demonstrates a candidate function, not a research finding or validated intervention.
